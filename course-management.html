Module Structure

Modules are automatically created based on the classification levels of video content:

  • Module 1: Biology (classificationLevel1 = 1)
  • Module 2: Chemistry (classificationLevel1 = 2)
  • Module 3: Mathematics (classificationLevel1 = 3)
  • Module 4: Physics (classificationLevel1 = 4)

Chapters within each module correspond to classificationLevel2 values.
